  # Suby Contacts

  A personal CRM built for high-velocity partnership work. Unified inbox across
  all messaging platforms, AI-powered reach-out suggestions, pipeline tracking,
  and a voice-first capture flow — all in one place.

  ## Why

  Managing partnerships across WhatsApp, Telegram, LinkedIn, X, and email from
  separate apps means context is always split. Suby Contacts brings every
  conversation into a single inbox, links messages to contacts automatically, and
  surfaces who to reach out to before you forget.

  ## Features

  - **Unified inbox** — WhatsApp, Telegram, LinkedIn, X, Discord, Slack, iMessage
  in one thread view, synced via Beeper
  - **AI reach-outs** — Scoring engine analyses last contact date, interaction
  frequency, and relationship strength to flag who needs attention
  - **Daily brief** — Morning summary pushed to Telegram with today's calls,
  overdue reminders, and top reach-out
  - **Voice capture** — Send a voice note to the Telegram bot → Whisper
  transcribes → Claude extracts the action → links to a contact
  - **Pipeline** — Kanban board (Intro → First call → Tech review → Term sheet →
  Live) with drag-and-drop and weighted pipeline value
  - **Pre-call prep** — Weekly calendar synced with Google Calendar, per-event AI
  brief with recent messages and relationship context
  - **Sequences** — Multi-step follow-up sequences with scheduling
  - **Network graph** — Visual map of contacts clustered by sector
  - **Reminders** — Bucketed by overdue / today / this week / later with snooze
  and platform links

  ## Getting Started
  
  ### Prerequisites

  - Node.js 20+
  - PostgreSQL database
  - Redis
  - Beeper Desktop running locally (for inbox sync)

  ### Setup
  
  ```bash
  git clone https://github.com/vinayjjjj/SubyCRM2.git
  cd SubyCRM2
  npm install

  Copy the environment file and fill in your values:

  cp .env.example .env.local

  Required environment variables:

  DATABASE_URL=           # PostgreSQL connection string
  DIRECT_URL=             # Direct PostgreSQL URL (for migrations)
  NEXT_PUBLIC_API_URL=    # Backend API URL (e.g. http://localhost:4002)
  BETTER_AUTH_SECRET=     # Random secret for auth
  ANTHROPIC_API_KEY=      # Claude API key
  OPENAI_API_KEY=         # Whisper transcription
  TELEGRAM_BOT_TOKEN=     # @subyassistant_bot token
  BEEPER_LOCAL_TOKEN=     # Beeper Desktop local API token

  Database

  npx prisma migrate deploy
  npx prisma generate

  Run

  # Terminal 1 — frontend (port 3005)
  npm run dev

  # Terminal 2 — backend API (port 4002)
  npm run server

  Open http://localhost:3005.

  Architecture

  Mock-first data layer

  Every page renders correctly even when the backend is offline. Each view tries
  the real API first, falls back to mock data if it fails. Once real data exists
  in the database, the mock fallback disappears automatically.

  Inbox sync

  Messages flow from native platforms → Beeper bridges → Matrix rooms → local
  Beeper Desktop API → Express webhook → PostgreSQL. Read receipts are propagated
  back the same way, so marking a message read in Suby also clears the unread
  badge in WhatsApp, Telegram, etc.

  AI pipeline

  Voice note → Telegram bot → Whisper (transcription) → Claude (extraction) →
  contact link → reminder/note

  Reach-out alerts are generated by scoring contacts on last interaction date,
  contact frequency, and relationship strength — no static rules, all derived from
  actual message history.
